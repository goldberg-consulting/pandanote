# Gallery demonstration vault

This is purpose-written sample content for Pandanote screenshots. All observations
are fictional. It contains no account credentials or personal working documents.

Copy this folder to a writable working location and open the copy as a Pandanote
vault. Start with **Field notes.md**. **Session analysis.md** contains small Python
calculations for the Variables panel; **Style guide.md** provides note context for
the assistant's `@` picker.

Use **Writing → Set Up Inkwell Workspace** if needed, then **Build PDF** to create
real publication output. Menu wording can vary by build; the Inkwell inspector also
provides setup and publishing actions. Code execution and PDF compilation require
the prerequisites documented in the repository README.

Keep generated `.inkwell` runs, PDFs, and `.pandanote` history in the working copy,
not in these example sources. For publication, capture the actual application UI;
do not substitute a mockup for a screenshot or fabricated text for an AI response.
